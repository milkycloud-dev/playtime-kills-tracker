# Changelog

## 1.0 (2026-09-25)

First public release.

- Playtime and hostile mob kills per player, lifetime and per day, in MySQL or MariaDB.
- Hostility from the core's entity category, so modded mobs count without per-mod lists.
- Farm protection: kill cap per chunk per hour and no kills while standing still.
- `/playtime`, `/playtime top`, `/playtime flush`.
- Optional per-kill journal with automatic cleanup.
